# Time Series Analyses on Housing Prices

## The Code
* `TayChenJiangNguyenLi-stat443project.Rmd` contains our code. It produces the HTML file `TayChenJiangNguyenLi-stat443project.html` and the PDF file `TayChenJiangNguyenLi-stat443project.pdf`.
* `01_data_wrangling.R`, `02_exponential_smoothing.R`, `03_arima.R`, `04_arimax.R`, and `05_forecast_comparison.R` contain the same code as `TayChenJiangNguyenLi-stat443project.Rmd`. We created them as separate R files for each step in the project for better readability.

## The Data
* `18100205.csv`, `IRSTCB01CAM156N.csv`, and `nhpi_with_interest_rate_1981_2023.csv` are datasets on housing and economic information from 1981 to 2023. We obtained them from Statistics Canada, merged them together, and filtered for the 3 cities we were most interested in: Vancouver, Montreal, and Toronto.
