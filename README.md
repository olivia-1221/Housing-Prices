# Time Series Analyses on Housing Prices

## Code
* `TayChenJiangNguyenLi-stat443project.Rmd` contains our code. It produces the HTML file `TayChenJiangNguyenLi-stat443project.html`.
* The numbered files `01_data_wrangling.R`, `02_exponential_smoothing.R`, `03_arima.R`, `04_arimax.R`, and `05_forecast_comparison.R` contain the same code as `TayChenJiangNguyenLi-stat443project.Rmd`: we created them as separate R files for each separate project step for better readability.

## Data
* `18100205.csv`, `IRSTCB01CAM156N.csv`, and `nhpi_with_interest_rate_1981_2023.csv` contain 1981-2023 housing and economic information which we sourced from Statistics Canada, merged, then filtered for the 3 cities we were most interested in: Vancouver, Montreal, and Toronto.
* The `Extracted_Cities` folder contains the 3 city-level datasets we created.
